# Vikas Kumhar — Portfolio

A modern, responsive portfolio starter built with Next.js, React, TypeScript, and Tailwind CSS v4. The design uses a warm paper-and-forest palette with editorial typography and CSS-built project artwork.

## Getting started

```bash
npm install
npm run dev
```

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Personalize it

- Update the name, intro, work, services, and contact details in `src/app/page.tsx`.
- Update the page title and description in `src/app/layout.tsx`.
- Tune colors, typography, and responsive styles in `src/app/globals.css`.

The project artwork is made in CSS, so no image files or backend are required. Tailwind CSS v4 is configured and available for adding utility classes as the site evolves.
